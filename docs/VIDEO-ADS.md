## "24 hours, 0 лв electric bill" — 6-scene timelapse ad

A Solaron "24 hours, 0 лв electric bill" 6-scene timelapse ad pasted an identical master-consistency prompt block at the start of every scene prompt (locking house/subject description so every generated image is recognizably the same subject), and gave 3 of the 6 scenes (sunrise/midday/sunset) an identical locked camera composition so they cross-dissolve into a single "one frame, whole day" morph — flagged in-thread as the sequence's strongest visual moment.

This is the source instance for the general master-consistency-block + bookend-composition technique documented in `sellinger.ai/docs/video-playbook/PLAYBOOK.md` §4.
